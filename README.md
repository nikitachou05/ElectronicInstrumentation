# ElectronicInstrumentation
This repository includes:
1) LabVIEW file
2) Video showing functioning project
3) Excel Data generated by the EMG controller
4) Lab Report detailing project

The game link is: https://supermarioplay.com/fullscreen

For this project, I used NI LabVIEW 2022 Q3 Professional Development System. I utilized the SetCursorPos function in the user32.dll library in LabVIEW. I used the stdcall(WINAPI) calling convention.
